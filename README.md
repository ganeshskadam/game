# GameVerse Premium Redesign

This project is a complete visual transformation of the existing gaming video platform into a cinematic, high-end UI.

## Pages
- `index.html` — Premium home with immersive hero + horizontal media row
- `game.html` — Game discovery with glow filter chips + live search
- `video-player.html` — Hero + large player + animated likes + related rail
- `join-team.html` — Floating join card + validation feedback + active players grid

## Highlights
- Layered cinematic background system (radial glows + vignette + animated light movement)
- Glassmorphism surfaces with neon depth and elevated shadows
- Card redesign with lift/zoom/glow hover behavior
- Scroll reveal animations via `ui-effects.js`
- Client-side interaction logic for filters, likes, related switching, and team join validation

## Run locally
Open `index.html` in a browser and navigate using the navbar.
