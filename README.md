# GameVerse UI Prototype

Frontend-only prototype implementing:

- Home page with sticky glass navbar, cinematic hero, and featured Free Fire cards.
- Free Fire game page with:
  - Hero banner
  - Filter chips (All, Funny, Angry, Naughty, Skills)
  - Instant client-side filtering + search
  - Responsive video grid and load-more
- Video player page with:
  - Large embedded YouTube player
  - Like button with pulse animation
  - Dynamic related videos list that updates the player in place
- Join Team premium page with:
  - Hero section + glass join card
  - Team code validation with shake error state
  - Active players grid with online indicators

## Run locally

Open `index.html` in a browser and navigate to `game.html`, `video-player.html`, and `join-team.html`.
